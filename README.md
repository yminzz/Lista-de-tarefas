# Minha Lista de Tarefas

Projeto de iniciante desenvolvido para praticar HTML, CSS e JavaScript.

## Funcionalidades

- Adicionar tarefas.
- Marcar tarefas como concluídas.
- Excluir uma tarefa.
- Remover todas as tarefas concluídas.
- Salvar tarefas no navegador usando `localStorage`.
- Mostrar quantas tarefas estão pendentes.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Digite uma tarefa e clique em **Adicionar**.

Não é necessário instalar dependências.

## O que pratiquei

- Seleção de elementos HTML com JavaScript.
- Eventos de formulário e clique.
- Funções, arrays e objetos.
- Criação de elementos na página.
- Uso de `localStorage` para salvar informações no navegador.
- Estilização com CSS e adaptação para telas menores.
